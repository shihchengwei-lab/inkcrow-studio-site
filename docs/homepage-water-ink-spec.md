# 首頁水墨與紙張陳化規格

- 本文記錄已確認的視覺方向與操作行為。實機效能與跨瀏覽器相容性仍須分別驗證。

## 1. 核心意象與適用範圍

首頁呈現「清水中散著淡墨，通透、安靜」：

- 人的動作擾動水流，使附近淡墨暈散。
- 停止操作後，墨保留餘韻，再慢慢聚攏，表達「作品慢慢成形」。
- 隨閱讀向下，紙張由清新逐漸轉為古畫藏品的質感；往上恢復新紙。
- 水墨涵蓋首頁全幅，配合整頁構圖分布。
- 隱私權政策與服務條款維持原樣。

## 2. 紙張、水墨與配色

| 元素 | 確定規格 |
|---|---|
| 水墨 | 偏中性的灰黑色，以稀釋、通透的濃淡與重疊呈現層次 |
| 頁首紙張 | 沿用既有紙色，清新明亮，纖維隱約可見 |
| 往下陳化 | 紙色逐漸向淡琥珀轉暖，纖維與局部深淺更明顯 |
| 邊緣沉色 | 既有深褐色，極淡、略不均勻，不形成整齊深色外框 |
| 頁尾程度 | 像妥善保存的古畫，溫潤泛黃，留白仍明亮 |
| 朱紅 | 保留原有用途，不混入紙張老化 |

不加入破洞、裂痕、霉斑或新印章。新增的灰黑色只用於水墨；文字與既有手繪素材維持原色。

紙纖維是底層質感，水墨呈現懸浮、流動的感覺。正文與素材保持清楚穩定，背景濃度不能妨礙閱讀。

## 3. 水墨分布與互動

聚墨區隨首頁內容延伸，配合各段留白安排；文字密集處更淡。具體位置需對照實際版面決定。

| 狀態 | 行為 |
|---|---|
| 初始安定 | 墨分布在各自的聚墨區，通透、疏鬆 |
| 游標移動／手指滑過 | 接觸處附近的水流帶開原有淡墨，影響向外柔和減弱 |
| 停止操作 | 墨沿原有動勢繼續漂移，保留短暫餘韻 |
| 歸攏 | 緩緩回到構圖安排好的區域，不收成濃黑實心團 |
| 安定之後 | 接近靜止，只容許極輕微的內部變化 |
| 再次擾動 | 從當下狀態接續，過程保持連貫 |

歸處固定，每次輪廓不完全相同。形狀變化延續先前擾動，讓邊緣、細絲與濃淡留下不同痕跡，不突然跳換形狀。

- 快速移動有擾動上限，不能造成整頁翻騰。
- 游標停住或手指按住不動時，不持續製造擾動。
- 點擊不增加噴墨、波紋或其他額外特效。
- 連結與按鈕維持正常操作。

## 4. 動態節奏與首次進場

動態節奏：

| 過程 | 時間 |
|---|---|
| 首次淡墨成形 | 約 4～6 秒 |
| 停止擾動後的餘韻 | 約 1～2 秒 |
| 餘韻後逐漸歸攏 | 約 6～10 秒 |

首次進場時，文字與手繪素材立即清楚可見，背景淡墨從稍微鬆散的狀態聚攏。訪客不必等待，可以直接閱讀、捲動與擾墨；中途操作自然接續當下的墨流。

播放規則：

- 同一瀏覽分頁第一次實際進首頁：播放一次完整淡墨成形；先開條款頁再第一次進首頁也播放。
- 同一分頁重新整理：直接呈現已大致聚攏的淡墨。
- 已進過首頁後，從條款頁返回：使用柔和的紙墨換頁過渡，散去後露出已大致聚攏的淡墨，不重播完整成形。
- 新開分頁進首頁：重新播放一次。

## 5. 捲動與紙張陳化

- 紙張新舊由當下捲動位置決定。
- 往下逐漸變成古紙，往上逐漸恢復新紙。
- 不累積永久老化，不依停留時間變舊。
- 紙色轉暖、纖維顯現與邊緣沉色分層漸變，避免只有整頁套黃色的感覺。
- 陳化發生在背景紙張，文字與手繪素材本身不變色。
- 捲動不額外改變水墨的歸攏速度，兩種互動各自保持可預期。

## 6. 手機體驗

手機保留首次成形、觸控擾墨與捲動陳化：

- 手指滑過時正常捲頁，同時擾動接觸處附近的淡墨。
- 不需要長按或切換互動模式。
- 手指離開後，墨繼續漂移，再慢慢歸攏。
- 頁面捲過的距離不能全部轉為撥水力道。
- 快速滑動的擾動有上限，正常捲動優先。

若效能不足，先降低水墨細節；仍影響捲動時，使用靜態替代呈現。效能判定由 `water-ink/controller.ts` 管理。

效能判斷只略過啟動或恢復後的首幀，連續活動中超過 250ms 的長幀仍須納入，避免最慢的情況反而無法降級。

## 7. 與既有效果的關係

| 既有效果 | 處理方式 |
|---|---|
| 首頁墨滴揭幕 | 移除，由淡墨慢慢成形取代 |
| 標題進場暈墨 | 取消，讓背景成形主導開場 |
| 標題游標停留暈墨 | 保留 |
| 線香煙霧 | 集中在線香附近，以連續煙絲及會消散的氣流回應游標、手指撥動；放手後恢復煙柱，保留正常捲頁，原圖不變 |
| 蝴蝶、竹雞 | 保留原圖。蝴蝶分層振翅，慢靠近時注意，太靠近或快速掃過時背離游標飛開；飛行中持續避讓，拉開距離才停棲，游標離開原位置才返回。竹雞使用原啄食畫格，游標靠近時先抬頭察覺、再以約 2–3.5px 微跳躲開，持續追近才再退；游標停住不連跳、遇界反向短跳。點擊先沉身蓄力、快速離地、緩一下落地，力度隨觸碰位置變化，遇界也反向，短跳約 20–32px、離地約 6–9px，微跳途中點擊會接一次較高跳躍，落地停頓後恢復；固定在按鈕右側留白，不出界、不擋按鈕，連點不累積。兩者 900px 以下維持隱藏；竹雞空間不足也隱藏，棲位區塊離屏或分頁隱藏時暫停，回來接續 |
| 捲動光影 | 改為紙張由新變舊 |
| 首頁與條款頁的墨色換頁轉場 | 先預載並在紙幕下切換，再從點擊位置約 250ms 柔邊向外揭示；不加入捲軸造型，遵守減少動態規則 |

## 8. 減少動態與替代呈現

系統開啟「減少動態」、瀏覽器無法執行水墨效果，或效能不足而需降級時：

- 保留靜態紙紋與已聚攏的淡墨。
- 不播放成形、漂移、歸攏或游標／觸控擾墨。
- 紙張採沿頁面固定分布：上方新紙、下方古紙。
- 捲動只是看見不同段落的紙張，不讓整個畫面持續變色。
- 閱讀、捲動、按鈕與連結照常運作。

## 9. 實作邊界與驗收條件

延續既有字體、手繪素材與靜態網站部署方式，不擅自新增套件。修改行為時須同步更新相關規格。

驗收重點：

- 首頁整體通透安靜，淡墨有水流感，散開與歸攏連貫。
- 墨回到固定區域，但不同操作留下不同輪廓；安定後接近靜止。
- 上下捲動可逆地呈現新紙與古紙。
- 內容始終清楚可讀，點擊、觸控與捲動不受阻。
- 首次進場、重新整理與返回首頁符合播放規則。
- 手機 390px、320px 寬度不橫向溢位，觸控擾墨不妨礙捲動。
- 減少動態與無法執行效果時，替代呈現正常。
- 條款頁維持原樣，既有換頁轉場正常。

## 10. 願力累積

- 三項效果共用同一個可見停留進度，前 30 秒保持基底，30–180 秒逐漸加深，180 秒達上限。
- 計時器掛在共用 root layout；首頁及條款頁可見時累積，分頁隱藏或 pagehide 時暫停，恢復不補算背景時間。同分頁條款往返、重新整理保留累積；儲存受限時，同一份頁面文件內仍可保留進度。
- 水墨濃度最多增加 15%，保留中央閱讀區較透的分布；動態與靜態墨色使用同一倍率。安定的水墨只在願力每秒變化時重畫一次，封頂後不再因累積而更新。
- 煙霧原有煙絲的透明度倍率最多增加 20%、線寬增加 8%；上升範圍依下節向圖外擴散。離屏不繪製，減少動態保留原始插畫。
- Logo 使用原圖與既有外圈遮罩增加淡墨暈，最高 0.22 透明度；中央圖形與文字不重畫，原有成形、重播、游標暈墨繼續運作。墨暈只在完整 Logo 顯示時呈現。
- 紙張陳化仍由捲動決定，蝴蝶與竹雞的互動節奏保持既有設定；不增加可見計分器或額外操作模式。

### 願力區域擴散補充

- 沿用同一個 30–180 秒進度。水墨中心留在原有兩側位置，水平滲透半徑由原本的 1 倍擴展至 2.3 倍；紋理不整片平移，中央閱讀區保留較低濃度。靜態替代同步擴大水平範圍。
- 煙絲壽命由 3.8 秒逐步延長至 8.2 秒，出圖上限由圖片上緣逐漸開展至上方 28% 圖寬，邊界柔和消散。繪圖區預留上方空間，不改動圖片尺寸或頁面排版。
- 每條煙流最多 237 個節點，氣流數量上限維持 32；圖外的煙也可接受手勢，監聽保持被動且只作用於煙霧區域，canvas 不攔截點擊。整個煙霧繪圖區離屏時暫停。

## 11. 實測範圍

實體手機的觸控手感、長時間耗電與發熱，以及 Safari、Firefox 與不同 GPU 的表現，仍需實機確認；桌面 Chromium 與手機視窗模擬不代替這些結果。
