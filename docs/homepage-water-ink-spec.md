# 首頁水墨與紙張陳化規格

- 確認日期：2026-10-24
- 狀態：使用者已確認最終本機預覽，並於 2026-10-24 授權提交、推送。
- 目前授權：將已確認版本提交並推送至 main。文末調整紀錄保留各輪決策，最終節奏以最後一項為準。
- 本文記錄已確認的視覺方向與操作行為。時間與強度採下列初始值，之後依實際畫面調整；不代表已完成效能或相容性驗證。

## 1. 核心意象與適用範圍

首頁呈現「清水中散著淡墨，通透、安靜」：

- 人的動作擾動水流，使附近淡墨暈散。
- 停止操作後，墨保留餘韻，再慢慢聚攏，表達「作品慢慢成形」。
- 隨閱讀向下，紙張由清新逐漸轉為古畫藏品的質感；往上恢復新紙。
- 水墨涵蓋首頁全幅，配合整頁構圖分布。
- 隱私權政策與服務條款維持原樣。

## 2. 紙張、水墨與配色

| 元素 | 確定規格 |
|---|---|
| 水墨 | 偏中性的灰黑色，以稀釋、通透的濃淡與重疊呈現層次 |
| 頁首紙張 | 沿用既有紙色，清新明亮，纖維隱約可見 |
| 往下陳化 | 紙色逐漸向淡琥珀轉暖，纖維與局部深淺更明顯 |
| 邊緣沉色 | 既有深褐色，極淡、略不均勻，不形成整齊深色外框 |
| 頁尾程度 | 像妥善保存的古畫，溫潤泛黃，留白仍明亮 |
| 朱紅 | 保留原有用途，不混入紙張老化 |

不加入破洞、裂痕、霉斑或新印章。新增的灰黑色只用於水墨；文字與既有手繪素材維持原色。

紙纖維是底層質感，水墨呈現懸浮、流動的感覺。正文與素材保持清楚穩定，背景濃度不能妨礙閱讀。

## 3. 水墨分布與互動

聚墨區隨首頁內容延伸，配合各段留白安排；文字密集處更淡。具體位置需對照實際版面決定。

| 狀態 | 行為 |
|---|---|
| 初始安定 | 墨分布在各自的聚墨區，通透、疏鬆 |
| 游標移動／手指滑過 | 接觸處附近的水流帶開原有淡墨，影響向外柔和減弱 |
| 停止操作 | 墨沿原有動勢繼續漂移，保留短暫餘韻 |
| 歸攏 | 緩緩回到構圖安排好的區域，不收成濃黑實心團 |
| 安定之後 | 接近靜止，只容許極輕微的內部變化 |
| 再次擾動 | 從當下狀態接續，過程保持連貫 |

歸處固定，每次輪廓不完全相同。形狀變化延續先前擾動，讓邊緣、細絲與濃淡留下不同痕跡，不突然跳換形狀。

- 快速移動有擾動上限，不能造成整頁翻騰。
- 游標停住或手指按住不動時，不持續製造擾動。
- 點擊不增加噴墨、波紋或其他額外特效。
- 連結與按鈕維持正常操作。

## 4. 動態節奏與首次進場

以下時間是試看起點，並非已驗證的最終數值：

| 過程 | 初始設定 |
|---|---|
| 首次淡墨成形 | 約 4～6 秒 |
| 停止擾動後的餘韻 | 約 1～2 秒 |
| 餘韻後逐漸歸攏 | 約 6～10 秒 |

首次進場時，文字與手繪素材立即清楚可見，背景淡墨從稍微鬆散的狀態聚攏。訪客不必等待，可以直接閱讀、捲動與擾墨；中途操作自然接續當下的墨流。

播放規則：

- 同一瀏覽分頁首次進首頁：播放一次完整淡墨成形。
- 同一分頁重新整理：直接呈現已大致聚攏的淡墨。
- 從條款頁返回首頁：使用柔和的紙墨換頁過渡，散去後露出已大致聚攏的淡墨，不重播完整成形。
- 新開分頁進首頁：重新播放一次。

## 5. 捲動與紙張陳化

- 紙張新舊由當下捲動位置決定。
- 往下逐漸變成古紙，往上逐漸恢復新紙。
- 不累積永久老化，不依停留時間變舊。
- 紙色轉暖、纖維顯現與邊緣沉色分層漸變，避免只有整頁套黃色的感覺。
- 陳化發生在背景紙張，文字與手繪素材本身不變色。
- 捲動不額外改變水墨的歸攏速度，兩種互動各自保持可預期。

## 6. 手機體驗

手機保留首次成形、觸控擾墨與捲動陳化：

- 手指滑過時正常捲頁，同時擾動接觸處附近的淡墨。
- 不需要長按或切換互動模式。
- 手指離開後，墨繼續漂移，再慢慢歸攏。
- 頁面捲過的距離不能全部轉為撥水力道。
- 快速滑動的擾動有上限，正常捲動優先。

若效能不足，先降低水墨細節；仍影響捲動時，使用靜態替代呈現。具體效能判定方式留待實作時決定，須以實測為準。

## 7. 與既有效果的關係

| 既有效果 | 處理方式 |
|---|---|
| 首頁墨滴揭幕 | 移除，由淡墨慢慢成形取代 |
| 標題進場暈墨 | 取消，讓背景成形主導開場 |
| 標題游標停留暈墨 | 保留 |
| 線香煙霧 | 集中在線香附近，以連續煙絲及會消散的氣流回應游標、手指撥動；放手後恢復煙柱，保留正常捲頁，原圖不變 |
| 蝴蝶、竹雞 | 保留原圖。蝴蝶分層振翅，慢靠近時注意，太靠近或快速掃過時背離游標飛開；飛行中持續避讓，拉開距離才停棲，游標離開原位置才返回。限定標題旁留白，900px 以下維持隱藏。竹雞行為不變 |
| 捲動光影 | 改為紙張由新變舊 |
| 首頁與條款頁的墨色換頁轉場 | 依最新回饋先預載並在紙幕下切換，再從點擊位置約 250ms 柔邊向外揭示；不加入捲軸造型，遵守減少動態規則 |

## 8. 減少動態與替代呈現

系統開啟「減少動態」、瀏覽器無法執行水墨效果，或效能不足而需降級時：

- 保留靜態紙紋與已聚攏的淡墨。
- 不播放成形、漂移、歸攏或游標／觸控擾墨。
- 紙張採沿頁面固定分布：上方新紙、下方古紙。
- 捲動只是看見不同段落的紙張，不讓整個畫面持續變色。
- 閱讀、捲動、按鈕與連結照常運作。

## 9. 實作邊界與驗收條件

延續既有字體、手繪素材與靜態網站部署方式，不擅自新增套件。日後獲准實作時，需同步更新設計規則中的動態與配色例外，以及相關行為文件。

驗收重點：

- 首頁整體通透安靜，淡墨有水流感，散開與歸攏連貫。
- 墨回到固定區域，但不同操作留下不同輪廓；安定後接近靜止。
- 上下捲動可逆地呈現新紙與古紙。
- 內容始終清楚可讀，點擊、觸控與捲動不受阻。
- 首次進場、重新整理與返回首頁符合播放規則。
- 手機 390px、320px 寬度不橫向溢位，觸控擾墨不妨礙捲動。
- 減少動態與無法執行效果時，替代呈現正常。
- 條款頁維持原樣，既有換頁轉場正常。

- 動態時間微調。
- 效能降級的判定方式。
- 桌面、手機的流暢度與瀏覽器相容性。

## 11. 本機預覽回饋調整（2026-10-24）

使用者確認水墨很好，因此保留水墨手感、構圖與節奏。依「紙質轉換有點輕、換頁轉場很硬」的回饋，加強古紙的暖色、纖維與輕微邊緣沉色，頁首新紙保持原樣；換頁改用柔邊淡墨與紙色承接，離開約 0.6 秒、新頁約 1 秒散去。正文不位移、不模糊，條款頁的日常背景與內容維持原樣。調整後的紙質與轉場仍待使用者試看。


## 第三次預覽調整（2026-10-24）

使用者指出前版只剩變灰與跳頁，希望約 250ms 的展開動畫，並在動畫期間預載；接著指定從點擊位置展開。本輪保留水墨與紙張陳化，改成以下換頁行為：

- 站內連結靠近視窗、游標移入、鍵盤聚焦或觸控時先預載；點擊時補預載，與約 80ms 覆幕同步進行。
- 使用頁內路由切換；新頁內容提交後回到頁首，再從點擊位置用約 250ms 柔邊向外揭示。鍵盤操作從連結中心展開。
- 資料較慢時保持紙幕，等內容就緒才揭示；6 秒仍未完成則移除遮幕，避免擋住操作。
- 不加入捲軸造型，正文不位移、不模糊；返回首頁不重播首次成形。外部連結、開新分頁、同頁錨點與瀏覽器上下一頁不播放轉場。減少動態時直接換頁，途中啟用減少動態也不取消導覽。

這取代上節的 0.6 秒覆起與 1 秒散去；視覺節奏仍以使用者本機試看為準。
